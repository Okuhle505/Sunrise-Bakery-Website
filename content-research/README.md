# Sunrise Bakery Part 1 Content Research Pack

This folder contains the source material and registers that support the Part 1 content-research submission. It is also packaged as `../SunriseBakery-Part1-Content-Research.zip`.

## Contents

- `text/original-content-register.md` - confirms which website text is original fictional content and maps it to the relevant page.
- `images/image-source-register.md` - lists every image placeholder used by the HTML files and the details required before replacing it.
- `documents/research-and-licensing-notes.md` - records the course brief and the image-licensing guidance consulted for the project.

## Important

No images are stored in this pack because no approved images have been supplied. Do not add an image without recording its creator, title/description, source URL, licence/permission, access date and intended filename in the image source register.
